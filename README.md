# Fence

Fence is an institutional-memory decision reviewer built for Hack with Bengaluru 4.0. It compares general advice on a proposal with advice grounded in earlier decisions and shows the evidence behind the recommendation.

Start with the [project README and setup guide](fence/README.md). The [architecture guide](fence/docs/ARCHITECTURE.md) explains the review and persistence paths, and the [demo guide](fence/docs/DEMO.md) includes screenshots from the synthetic Lotus example.
